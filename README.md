# My Game Engine v0.3.0

한국어 블록으로 PC·모바일용 2D 게임을 만드는 웹 편집기입니다. 편집기와 내보낸 게임은 같은 실행 코드와 Canvas2D 렌더러를 사용합니다.

## 게임 만들기

1. 오브젝트를 추가하고 원·사각형·이미지·글자 모양을 정합니다. 무대에서 끌어 위치를 바꾸거나 X·Y 값을 입력합니다.
2. 오브젝트마다 `게임이 시작되었을 때` 또는 `클릭하거나 터치했을 때` 블록에 동작을 연결합니다.
3. `자료`에서 변수를 만들고 값 정하기·값 바꾸기 블록을 사용합니다. 이름이 같은 변수는 오브젝트와 장면 사이에서 공유됩니다. 사용자 블록의 매개변수는 호출 안에서만 사용됩니다.
4. 점수판은 글자 오브젝트와 `글자 표시하기` 블록으로 만듭니다. `문자열 연결` 블록으로 “점수: ”와 점수 변수를 합칠 수 있습니다.
5. 장면을 추가·복제·삭제할 수 있습니다. 마지막 장면은 유지되며, 최근에 삭제한 장면은 `삭제 되돌리기`로 복원합니다. 장면과 오브젝트 이름 변경 시 관련 블록의 이름도 갱신합니다. 없는 장면·오브젝트·소리를 참조하면 `블록 연결 확인`에 표시합니다.
6. 장면 설정에서 가로 4:3, 가로 16:9, 세로 9:16, 정사각형 또는 직접 해상도를 지정합니다. PC·모바일에서 비율을 유지하며 크기가 조정됩니다.
7. `실행`으로 확인하고 `중지`로 편집에 돌아옵니다. 모바일에서는 실행 시 무대가 열립니다. 마우스·터치 좌표 블록, 누름 판단, 클릭·터치 이벤트로 직접 조작을 만들 수 있습니다. 방향키 게임은 모바일 화면 쓸기로도 조작됩니다.

## 저장과 배포

- 브라우저의 IndexedDB에 자동 저장됩니다. 중요한 프로젝트는 `저장`으로 `.mge.json` 파일을 보관하세요.
- `HTML 내보내기`는 게임 실행 코드, 장면, 오브젝트, 블록, 이미지와 소리를 담은 독립 실행 단일 HTML 파일을 만듭니다. 서버·CDN·외부 라이브러리가 필요하지 않으며 파일을 열면 자동 실행합니다.
- 내보낸 화면에는 게임 캔버스만 표시합니다. 편집기 버튼이나 방향 버튼을 덧붙이지 않습니다. 전체 화면은 브라우저 기능으로 사용할 수 있습니다.
- `열기`에서 JSON이나 내보낸 HTML을 선택하면 해상도·장면·오브젝트·블록·이미지·소리를 편집 가능한 프로젝트로 복원합니다. 같은 프로젝트를 다시 열어도 새 파일의 블록을 불러옵니다.
- 이전 프로젝트는 자동 보정되며 해상도가 없으면 480 × 360을 사용합니다.

## 블록과 리소스

- 시작·클릭·터치 이벤트, 반복·조건·대기·게임 중지
- 이동·회전·크기·표시·숨김·글자 표시
- 숫자·문자열·문자열 연결·변수 설정과 변경
- 키보드·표준 게임패드·마우스·터치 입력, 포인터 좌표·오브젝트 속성·화면 크기·경과 시간
- 다른 오브젝트 또는 이름으로 지정한 오브젝트에 닿았는지 판단
- 중력·속도·충격·튕김, 화면 경계와 오브젝트 충돌
- 카메라 위치·확대·따라가기 및 해제, 장면 전환
- `내 블록`에서 매개변수가 있는 명령 블록 정의와 호출. 반환값이 있는 사용자 블록은 제공하지 않습니다.
- PNG·JPEG·WebP 이미지 파일당 2MB. 같은 크기의 다른 이미지로 교체하거나 이미지를 지울 수 있습니다.
- 소리 파일당 5MB, 전체 20MB, 최대 32개. 같은 이름은 자동 구분하며 파일을 프로젝트에 포함합니다. 브라우저 소리 재생은 최초 터치·키 입력이 필요할 수 있습니다.
- 프로젝트 파일(JSON·HTML) 불러오기 최대 128MB.

## 개발 및 검증

Node.js 22.22.2 이상 또는 24.15 이상이 필요합니다.

```bash
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

`npm run build`는 TypeScript 검사 후 정적 배포 파일을 `dist`에 만들고 GitHub Pages용 루트 파일도 갱신합니다. CI는 런타임·프로젝트 회귀 검사와 Chromium 브라우저 검사를 통과한 빌드를 게시합니다.

브라우저 검사는 장면 삭제·복원·복제, 자동 저장, 같은 ID 프로젝트 다시 열기, 점수·변수·사용자 블록·장면 전환, 오프라인 모바일 HTML 실행, 해상도 입력, 이미지 교체와 겹침 순서를 확인합니다.

## 범위

물리 충돌은 단순한 축 정렬 외곽으로 계산합니다. 복잡한 충돌 모양·관절·픽셀 충돌은 제공하지 않습니다. HTML에 포함한 게임 코드와 편집 데이터는 파일을 받은 사람이 볼 수 있습니다.

편집기: React, TypeScript, Vite, Blockly. 실행기: 브라우저 Canvas2D·Pointer Events·Gamepad API.
