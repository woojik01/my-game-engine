# My Game Engine — 초기 개발 버전

한국어 블록으로 2D 게임을 만드는 PC·모바일 웹 편집기입니다. 이 코드는 v0.1.0의 **검증 전 개발본**이며 아직 완성판이 아닙니다.

## 실행

Node.js 22.12 이상을 설치한 뒤 프로젝트 폴더에서:

```bash
npm ci
npm run dev
```

터미널에 표시된 주소를 브라우저로 엽니다. `npm run build`로 배포용 `dist`를 만들고, `npm test`로 실행 엔진의 일부 기능을 확인합니다.

## 사용

첫 화면에는 방향키 이동 예제가 있습니다. 블록을 수정하고 ▶ 실행을 눌러 결과를 확인합니다. 중지하면 편집 상태로 돌아갑니다. 오브젝트를 선택하면 해당 블록 조립소가 나타납니다. 오브젝트의 모양, 색, 위치와 크기를 속성에서 변경하거나 무대에서 끌어 놓을 수 있습니다. 이미지는 PNG/JPEG/WebP, 2MB 이하를 선택할 수 있습니다.

프로젝트는 현재 브라우저의 IndexedDB에 자동 저장됩니다. **저장** 버튼은 프로젝트 파일을 다운로드하고 **열기**는 이 파일을 가져옵니다. 브라우저 데이터를 지우면 자동 저장도 삭제되므로 파일을 따로 보관하세요. 장면을 추가하고 이름과 배경색을 바꿀 수 있습니다.

## 구현된 구성

- Blockly 블록 조립소와 오브젝트별 JSON 직렬화, 실행 취소·다시 실행
- 실행/중지, 시작·오브젝트 클릭 이벤트, 반복·조건·대기, 움직임·생김새·판단·계산·변수 블록
- Phaser 무대, 기본 도형과 이미지, 터치 방향 버튼, 충돌의 기본 사각형 판정
- 장면별 오브젝트, 자동 저장 및 파일 가져오기/내보내기
- 반응형 레이아웃과 GitHub Pages용 Actions 워크플로

반복문은 주기적으로 프레임에 제어권을 반환합니다. 실행은 편집 객체의 복사본에서 처리합니다. 소리 블록은 간단한 효과음을 만들며 오디오를 사용할 수 없어도 실행을 중단하지 않습니다.

## 알려진 제한 및 미검증 사항

- PC·모바일 실제 브라우저 상호작용, 터치 연결과 표시, 화면 겹침, 콘솔 오류, IndexedDB 복구, 이미지 표시 및 GitHub Pages 배포는 **아직 검증하지 못했습니다**.
- PWA 설치 및 오프라인 캐싱, 블록 검색, 전용 모양·소리 탭, 사용자 음원 추가, 프로젝트 목록 및 설정은 없습니다.
- 사각형 경계 기반 충돌 판정은 회전된 모양과 이미지의 투명 영역을 반영하지 않습니다. 장면 전환 블록, 게임 내보내기, 물리 반응은 없습니다.
- 현재 변수 ID는 Blockly 작업 공간 단위로 저장되므로 다른 오브젝트 사이에 공유하는 변수 기능은 제공하지 않습니다.
- 이미지 렌더링, 객체 레이어, 모바일 입력 및 긴 실행에서 안정성 검증이 필요합니다. 저장 파일은 신뢰할 수 있는 출처의 것만 사용하세요.
- GitHub Pages 워크플로는 제공하지만 저장소의 Pages 소스가 GitHub Actions로 설정되어 있지 않으면 자동 배포되지 않습니다.

## 기술과 설계

React, TypeScript, Vite, Blockly, Phaser, IndexedDB를 사용합니다. Blockly JSON 직렬화와 독립 실행 인터프리터를 통해 향후 블록을 추가할 수 있도록 구성했습니다. 이 실행기는 아직 물리·애니메이션 엔진이 아닙니다. TypeScript 7의 실행 바이너리가 개발 환경에서 실행되지 않아 5.9 계열을 사용했습니다. 정확한 패키지 버전은 `package-lock.json`을 확인하세요.

참고: [Blockly 저장 및 불러오기](https://docs.blockly.com/guides/configure/serialization/), [Phaser 설치](https://docs.phaser.io/phaser/getting-started/installation), [Vite 시작하기](https://vite.dev/guide/), [GitHub Pages 배포](https://vite.dev/guide/static-deploy.html).
