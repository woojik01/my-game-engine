# My Game Engine v0.2.4

한국어 블록으로 2D 게임을 만드는 PC·모바일 웹 편집기입니다. 오브젝트를 고르고 블록을 연결해 실제 무대에서 실행할 수 있습니다.

## 실행

Node.js 22.12 이상 또는 24 이상이 필요합니다.

```bash
npm ci
npm run dev
```

배포 파일은 `npm run build`로 생성합니다. GitHub Pages가 `main` 루트를 게시할 수 있도록 빌드가 루트 `index.html`, `assets/`, 매니페스트, 서비스 워커도 갱신합니다. 엔진 검사는 `npm test`로 실행합니다.

## 시작하기

1. 처음 열면 방향키 이동 예제가 표시됩니다.
2. `▶ 실행`을 누르고 키보드, 화면 방향 버튼 또는 연결된 표준 게임패드로 플레이합니다.
3. `중지`를 눌러 편집으로 돌아와 블록과 속성을 바꿉니다.
4. 오브젝트와 장면을 추가하고, 장면 설정에서 게임 기준 해상도를 고릅니다. 가로 4:3, 가로 16:9, 세로 9:16, 정사각형 또는 직접 크기를 지원합니다.
5. `저장`은 편집 가능한 `.mge.json`을 내보내고 `열기`는 JSON 프로젝트 또는 엔진에서 내보낸 HTML을 가져옵니다. HTML을 열면 해상도, 장면, 오브젝트, 블록, 이미지, 소리를 편집 가능한 프로젝트로 복원합니다. 브라우저에는 IndexedDB로 자동 저장됩니다.
6. `HTML 내보내기`는 별도 서버나 라이브러리 없이 실행되는 단일 HTML5 게임을 만듭니다. 파일에는 게임 화면만 표시되며 PC·모바일 화면 크기에 맞춰 기준 비율을 유지합니다. 모바일에서는 오브젝트 탭과 화면 누르기 블록을 사용할 수 있고, 방향키 입력은 화면을 쓸어 조작할 수 있습니다. 전체 화면 모드는 브라우저 자체 기능으로 켜세요.

이전 프로젝트 형식은 자동 보정됩니다. 기존 장면, 오브젝트, 블록, 리소스를 유지하고 기준 해상도는 480 × 360으로 설정합니다.

## 기능

- Blockly 한국어 블록 편집, 실행/중지, 오브젝트별 작업 공간, 블록 되돌리기·다시 실행
- 시작·클릭 이벤트, 조건·반복·대기, 이동·모양·판단·계산·변수 블록
- 이름으로 호출하는 인자 없는 사용자 블록: `내 블록` 카테고리에서 정의와 호출 블록을 추가합니다.
- 기준 해상도 프리셋 및 직접 입력, PC·모바일 대응 비율 유지
- 오브젝트 중력, 속도·충격 설정, 화면 경계·오브젝트 충돌과 반발
- 카메라 위치·확대, 선택 오브젝트 따라가기, 카메라 블록
- 장면 전환 블록: 장면 이름을 입력하면 해당 장면과 시작 블록으로 전환합니다.
- 표준 게임패드 버튼·아날로그 스틱 입력을 판단 블록에서 사용
- 소리 파일 추가와 미리 듣기, 효과음 블록. 파일은 프로젝트에 포함되며 파일당 최대 5MB입니다.
- Phaser 무대, 도형·이미지 오브젝트, PC·모바일 반응형 UI, 편집기 실행용 화면 방향 버튼
- 실행 시 무대에 키보드 포커스를 주고, 편집 작업 공간의 키 입력을 우선 수신합니다. 브라우저별 방향키 이름 차이도 표준 키 이름으로 맞춥니다.
- 독립 실행 단일 HTML5 게임 내보내기, PWA 설치 정보 및 같은 출처 자산 오프라인 캐시

## 블록 사용 방법

- `물리`: 물리 켜기/끄기, 속도 설정, 힘 더하기. 장면의 중력과 게임 화면 경계가 물리에 반영됩니다.
- `카메라`: 위치 이동, 배율 변경, 이름으로 오브젝트 따라가기.
- `흐름`: 장면 바꾸기 블록의 입력 칸에 프로젝트 장면 이름을 입력합니다.
- `소리`: 파일 이름을 입력합니다. 이름이 일치하는 파일이 없으면 기본 짧은 효과음을 재생합니다.
- `내 블록`: Blockly의 프로시저 정의와 호출 블록을 사용합니다. 현재 인자·반환값이 있는 사용자 블록은 지원하지 않습니다.
- `자료`: Blockly 변수 블록으로 각 실행의 변수를 관리합니다.

## 제한 사항

- 물리 충돌은 원·사각형 외곽을 단순한 축 정렬 상자로 근사합니다. 복잡한 충돌 모양, 조인트, 관절, 픽셀 단위 충돌은 없습니다.
- HTML5 내보내기 결과는 별도 의존성 없이 실행되는 Canvas2D 게임입니다. 화면에 게임 캔버스 외 버튼을 덧붙이지 않으며, 블록과 프로젝트 데이터, 이미지·소리 리소스를 HTML 안에 포함합니다. 편집 데이터도 함께 들어 있어 엔진의 `열기`에서 HTML을 다시 불러와 편집할 수 있습니다.
- 사용자 블록은 인자 없이 호출하는 명령 블록만 지원합니다.
- 게임패드는 브라우저의 표준 Gamepad API와 연결 권한 정책을 따릅니다.
- 오브젝트 이미지는 파일당 2MB, 프로젝트 파일(JSON 또는 HTML) 가져오기는 32MB까지 허용합니다.
- 오프라인 편집은 해당 브라우저에 앱 캐시와 프로젝트 데이터가 저장되어 있어야 합니다. 중요한 프로젝트는 `.mge.json`으로도 보관하세요.
