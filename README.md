# My Game Engine v0.1.0

한국어 블록으로 2D 게임을 만드는 PC·모바일 웹 편집기입니다. 오브젝트를 고르고 블록을 연결해 실제 무대에서 실행할 수 있습니다.

## 실행

Node.js 22.12 이상 또는 24 이상을 준비한 뒤 프로젝트 폴더에서 실행합니다.

```bash
npm ci
npm run dev
```

개발 서버 주소를 브라우저에서 엽니다. 배포용 파일은 `npm run build`로 `dist/`에 생성됩니다. 핵심 실행기 검사는 `npm test`로 실행합니다.

## 시작하기

1. 첫 화면의 `플레이어` 오브젝트와 방향키 이동 예제를 확인합니다.
2. `▶ 실행`을 누르고 방향키 또는 화면 방향 버튼으로 플레이어를 움직입니다.
3. `중지`를 눌러 편집으로 돌아온 다음 블록과 속성을 바꿔 다시 실행합니다.
4. `＋ 추가`로 오브젝트를 만들고, 오브젝트를 선택해 독립된 블록을 편집합니다.
5. `저장`은 `.mge.json` 프로젝트 파일을 내려받고 `열기`는 파일을 가져옵니다. 브라우저에는 현재 프로젝트가 IndexedDB로 자동 저장됩니다.

무대에서는 오브젝트를 드래그해 위치를 바꿀 수 있습니다. 장면을 추가하고 이름과 배경색을 설정할 수 있습니다. 모바일에서는 장면·오브젝트·블록·모양·소리 탭을 사용합니다.

## 구현 기능

- Blockly JSON 블록 편집, 한국어 카테고리, 블록 되돌리기·다시 실행
- 시작 및 오브젝트 클릭 이벤트, 반복·조건·대기, 움직임·생김새·판단·계산·변수 블록
- Phaser 2D 무대, 도형·이미지 오브젝트, 위치·방향·크기·표시·순서, 기본 사각형 충돌 판정
- 키보드·터치 입력, 안전하게 중지할 수 있는 반복 실행, 기본 효과음
- 오브젝트별 작업 공간, 장면·오브젝트 편집, 자동 저장, 프로젝트 파일 가져오기·내보내기
- 모바일 전용 탭 레이아웃, PWA 설치 메타데이터 및 HTTPS·localhost 오프라인 캐시
- GitHub Pages 자동 배포 워크플로

## 제한 사항

- 오브젝트 간 변수 공유, 사용자 오디오 파일 추가, 복잡한 장면 전환, 물리 반응, 타일맵, 카메라, 게임 내보내기 기능은 아직 없습니다.
- 이미지의 투명 영역이나 회전 형태를 반영하는 픽셀 정밀 충돌은 지원하지 않습니다.
- PWA 캐시는 앱 파일을 오프라인으로 열어 주지만 외부 사이트나 CDN 리소스는 캐시하지 않습니다. 프로젝트 데이터는 브라우저 저장 공간을 지우면 사라질 수 있으므로 파일로도 보관하세요.
- 브라우저 정책상 서비스 워커는 HTTPS 또는 localhost에서만 등록됩니다.

## 기술 및 문서

- React 19.3.1, TypeScript 5.9.3, Vite 8.3.5
- Blockly 13.4.0의 JSON 직렬화로 블록 작업 공간을 저장·복원합니다. 신규 프로젝트에서는 JSON 직렬화를 권장한다는 Blockly 공식 가이드를 따랐습니다: [Blockly 저장 및 불러오기](https://docs.blockly.com/guides/configure/serialization/).
- Phaser 4.2.1을 무대 렌더러로 사용합니다: [Phaser 설치](https://docs.phaser.io/phaser/getting-started/installation).
- GitHub Pages 배포는 Vite의 정적 사이트 배포 안내를 참고합니다: [Vite GitHub Pages 배포](https://vite.dev/guide/static-deploy).
